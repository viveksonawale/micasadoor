# Font Shorthand Rules

When generating or modifying code, if the user asks to use "Font A", "Font B", or "Font C", follow these exact mappings:

- **Font A** = **Playfair Display**
  - CSS implementation: `font-family: var(--font-playfair), 'Playfair Display', serif;`

- **Font B** = **Cabinet Grotesk**
  - CSS implementation: `font-family: 'Cabinet Grotesk', sans-serif;`

- **Font C** = **JetBrains Mono**
  - CSS implementation: `font-family: 'JetBrains Mono', monospace;`

Always apply the corresponding font family string when these shorthands are mentioned.
